# mise.lock Adoption Implementation Plan (DESIGN.md §8)

**Goal:** repo holds `mise.lock`; global `~/.config/mise/mise.lock` symlinks to it; mison regenerates after every apply (best-effort) and commits/pushes when changed.

**Design (approved §8):** lock is DERIVED state — never semantic-merged (rides reset/commit paths). `mise lock --global` writes through the symlink into the env repo. Network failures → warn-and-defer. Schema guard does not apply.

## Tasks
1. **paths**: Layout gains `MiseLock` (env dir) + `GlobalLock` (XDG); Ensure creates second symlink via generalized `ensureSymlink(path, target)`. Same replace-foreign-file policy as config.toml. TDD in paths_test.go.
2. **Flows.refreshLock() bool**: read lock before → `Mise.Exec("lock", "--global")` → read after; error → Warn + false; returns changed.
3. **install/uninstall**: `refreshLock()` after mise apply, BEFORE commitAndPush → lock lands in the same "install:/uninstall:" commit.
4. **sync**: after apply+prune, `if f.refreshLock() { commitAndPush("mison: refresh lock", policy) }`.
5. **init**: same hook after `mise install`.
6. **Integration**: FastForward pull checks out remote mise.lock (real-git test).
7. **Docs**: DESIGN.md §8 status → implemented; BEHAVIOR.md rows; `make lint && make test && make build`.

Test fakes: fakeMise gains `lockResult string` — Exec("lock","--global") writes the lock file (side effect) when set.
